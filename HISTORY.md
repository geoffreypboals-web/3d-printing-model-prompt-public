# History

This repository is a fresh public copy, published as one commit. The private working repository's history is summarised here rather than copied.

- **Started:** August 2026.
- **Size at release:** 111 commits, up to November 2026.
- **Main stages, in order:**
  1. Text-prompt to printable-model service: complexity classifier, OpenSCAD and Blender generators, and a web page.
  2. Local LLM support through Ollama, with a Docker deployment.
  3. Silicone mold generation and print-readiness checks.
  4. Print tools: split to fit, thumbnails, gridfinity bins, lithophanes, QR tags, tool inserts and multi-colour 3MF export.
  5. CadQuery and FreeCAD geometry, caller-written OpenSCAD, and supply-chain CI.
  6. A launcher that finds free host ports.
- **Contributors:** the project owner, working with AI coding agents.
